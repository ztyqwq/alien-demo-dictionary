# Alien Demo Dictionary

《Message from Aliens》Demo 字形字典。网站提供字形一览、部件查询、完整字典释义和到达路径。

在线地址：<https://ztyqwq.github.io/alien-demo-dictionary/>

旧版地址：<https://ztyqwq.github.io/alien-demo-dictionary/old/>，保留 2026-10-19 游戏更新前的 703 字数据库。首次访问会复制当前浏览器已有释义，此后新旧版的释义、对比颜色及写作草稿分别保存。历史原始快照保存在 `old` 分支；公开的旧版页面由 `main` 分支下的 `old/` 目录提供，不改变主站发布分支。

数据库对应 Demo Build 26043865，收录 730 个可达字形；字形、字典定义、部件索引、出处和完整点击路线同步更新。已移除失效的旧固定字典左页入口，重新计算剩余路线；内置字典中依赖已有注释的列表不作为发现新字的入口。图集采用内容版本缓存，避免更新后仍显示旧字形。

支持一次导入多个游戏存档，开启“存档对比”后，在每个字下用两排显示所选存档的个人释义。可切换、交换、重命名和移除存档，各份存档的网页修改分别保存在浏览器中；不会写回游戏文件。

对比时，释义查询和外星写作同时搜索两份存档；进度、未破译筛选和高亮以存档 1 为准。旧版单存档缓存会自动迁移。

对比底色仅显示在个人释义区域：释义相同为浅绿，文字相似度至少 50% 为浅黄，其余为浅红；两边均未填写时不着色。字形、字框和按钮保留原来的底色和尺寸。单字页支持为这个字的释义手动改色、恢复自动判断，手动标记按存档组合保存在当前浏览器，不影响其他字。相似度采用 Unicode 字符编辑距离，忽略首尾空白并进行 NFC 规范化；隐藏释义时，对比底色也随之隐藏。
